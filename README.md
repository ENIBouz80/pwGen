# ランダムなパスワードを生成する。

画面を開いた瞬間、ランダムなパスワードを生成して表示します。
パスワードの長さ(文字数)や、記号を含むか含まないかを指定して、再度生成できます。

## 使い方:
- URLを指定し、画面を開くと、画面を開いた瞬間、ランダムなパスワードを生成して表示します。
- 画面の中で、パスワードの長さ(文字数)や、記号を含むか含まないかを指定して、再度生成できます。
  - パスワードの長さ(文字数): 8 ～ 24 文字 (デフォルト 16文字)
  - 記号を含むか含まないか:  (デフォルト 含む)
- URLのクエリーストリングを指定することで、画面初期表示時の設定を変更できます。
  - クエリーパラメータ "len": パスワードの長さ(文字数)
    - 指定可能な最小値/最大値の範囲を超える値が指定された場合は、最小値/最大値に丸めます。
  - クエリーパラメータ "useSymbol": 記号を含むか含まないか
    - "1" or "true": 含む
    - "0" or "false": 含まない
  - 例)
    - "?len=12&useSymbol=0" を指定: 文字数=12、記号を含まない文字列が初期表示されます。

## 特徴:
- 生成される文字列には、英大文字、英小文字、数字 が必ず1文字は含まれます。
- 記号を含むようにした場合は、生成される文字列には、上記に加え、記号 が必ず1文字は含まれます。
- 生成されたパスワードを手書きで転記する場合を想定し、判読が難しい文字は除外するようにしています。
  - 小文字の"l"と大文字の"I"は、数字の"1"と区別がつきにくいので、生成される文字列には含まれません。
  - 大文字の"O"は、数字の"0"と区別がつきにくいので、生成される文字列には含まれません。
- 記号は、"!", "#", "$", "_" の4種類だけが使われます。
- 同じ文字が連続して並んで出てくることはありません。
